# Analisis Data Waktu Respons Database

Dashboard statistik deskriptif untuk tugas Statistika (GitHub Pages).

- Edit **hanya** `data.js` untuk mengganti judul, nama, teks, dan angka.
- Buka `index.html` di browser untuk melihat hasilnya secara lokal.
- Situs publik: https://USERNAME.github.io/NAMA-REPO/  (ganti USERNAME dan NAMA-REPO)

Struktur: `index.html` (kerangka), `style.css` (tampilan), `app.js` (hitung statistik dan grafik), `data.js` (data dan teks), `assets/chart.umd.js` (Chart.js 4.4.1, MIT).
